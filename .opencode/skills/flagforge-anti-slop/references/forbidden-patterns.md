# Forbidden Visual Patterns

High severity:
- neon green on black hacker theme
- Matrix rain
- emoji as core UI iconography
- generic cybersecurity stock art
- huge decorative glow/gradient backgrounds
- glassmorphism as the default surface system

Medium severity:
- generic dashboard card grid on every page
- too many pills
- same corner radius everywhere
- excessive shadows
- repeated entrance animations
- center-everything composition
- generic trophy/flame/shield symbolism

Review question:
Would a strong human designer have made this exact choice intentionally for a CTF competition platform?
If uncertain, simplify or recompose.
