# FlagForge Typography

Roles:
- Display: major page titles, challenge titles, large rank/score numerals.
- UI: navigation, buttons, labels, compact controls.
- Body: descriptions and explanatory copy.
- Technical: commands, flags, hashes, IPs, code, packet/request data.

Rules:
- Build hierarchy with scale, weight, spacing, and line height.
- Keep body copy highly readable.
- Use technical/monospace typography only when the content is genuinely technical.
- Avoid giant blocks of uppercase text.
- Use uppercase micro-labels only where helpful.
- Do not make every metadata item tiny, bold, uppercase, or pill-shaped.
