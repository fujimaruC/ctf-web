# FlagForge Geometry

Use geometry to create recognition.

Hierarchy:
- small radii for compact controls
- medium radii for buttons and inputs
- restrained radii for ordinary surfaces
- stronger framing for challenge workspaces
- technical dividers and occasional clipped/cut edges when useful

Avoid:
- identical radius everywhere
- nested rounded containers
- pill-shaped everything
- giant floating cards for every section

Prefer:
- thin structural lines
- open layouts
- intentional negative space
- asymmetric framing
- visual grouping without always using a card
