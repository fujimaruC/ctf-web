# FlagForge Motion

Good motion:
- navigation transitions
- state changes
- solve confirmation
- reveal/unlock
- progression
- subtle hover/focus feedback
- leaderboard state changes

Bad motion:
- fade-up on every card
- infinite floating objects
- random bounce
- constant shimmer
- decorative particle motion without purpose

Reference timing:
- fast: 100–160ms
- normal: 180–280ms
- emphasis: 300–500ms

Always support reduced motion.
