# SVG Visual Grammar

Stroke:
- thin for structure/decorative elements
- regular for normal icons
- stronger for active/important symbols

Geometry:
- circles
- arcs
- lines
- nodes
- cuts
- directional forms
- modular structures

Avoid noisy micro-detail and generic shield/lock clichés.

Fill:
- outline-first for interface icons
- fills for active states, silhouettes, brand marks, rank emphasis

Color:
Prefer currentColor.
Use design-system semantic colors only when semantics require them.

Accessibility:
Decorative SVG => aria-hidden.
Meaningful SVG => title/label when necessary.
